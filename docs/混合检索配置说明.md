# 混合检索配置说明

## 问题

```
ValueError: to enable hybrid mode, it must be set in retrieval strategy
```

## 原因

在新版本的 llama_index 中，混合检索模式需要在 **vector store 层面**配置，而不是在 **query engine 层面**配置。

## 解决方案

### 正确的配置方式

**在 vector store 创建时设置混合检索模式：**

```python
# rag/ingestion.py
from llama_index.core.vector_stores.types import VectorStoreQueryMode

def get_vector_store():
    return ElasticsearchStore(
        es_url=settings.ELASTICSEARCH_URL,
        index_name=settings.INDEX_NAME,
        vector_store_query_mode=VectorStoreQueryMode.HYBRID,  # ✅ 在这里设置
    )
```

**在 query engine 创建时不需要再设置：**

```python
# services/rag_service.py
query_engine = index.as_query_engine(
    similarity_top_k=similarity_top_k,
    node_postprocessors=node_postprocessors,
    filters=filters
    # ❌ 不需要：vector_store_query_mode="hybrid"
)
```

## 混合检索的工作原理

### 什么是混合检索？

混合检索（Hybrid Search）结合了两种检索方式：

1. **向量检索（Vector Search）** - 基于语义相似度
   - 使用 embedding 计算相似度
   - 适合语义相关但词汇不同的查询
   - 例如："机器学习" 和 "AI" 语义相似

2. **关键词检索（BM25/Lexical Search）** - 基于词汇匹配
   - 使用传统的 TF-IDF/BM25 算法
   - 适合精确词汇匹配
   - 例如：搜索特定术语 "Transformer"

### 混合检索的优势

通过结合两种方式，可以：
- ✅ 同时利用语义理解和精确匹配
- ✅ 提高检索准确率
- ✅ 减少遗漏相关文档

### Elasticsearch 中的混合检索

Elasticsearch 原生支持混合检索：
- **Dense Vector** - 向量检索
- **BM25** - 关键词检索
- **Hybrid** - 自动结合两者，使用 RRF (Reciprocal Rank Fusion) 算法

## 配置选项

### VectorStoreQueryMode 的选项

```python
from llama_index.core.vector_stores.types import VectorStoreQueryMode

# 1. 纯向量检索（默认）
VectorStoreQueryMode.DEFAULT

# 2. 纯关键词检索
VectorStoreQueryMode.SPARSE

# 3. 混合检索（推荐）
VectorStoreQueryMode.HYBRID

# 4. 基于 MMR 的检索（多样性）
VectorStoreQueryMode.MMR
```

### 权重调整（alpha 参数）

在某些 vector store 中，可以调整混合检索的权重：

```python
# alpha = 0.0 : 纯 BM25
# alpha = 0.5 : 均衡（推荐）
# alpha = 1.0 : 纯向量检索
```

**注意**：在当前配置中，Elasticsearch 使用 RRF 算法自动平衡，不需要手动设置 alpha。

## 故障排查

### 如果混合检索不工作

1. **检查 Elasticsearch 版本**
   ```bash
   curl http://localhost:39200
   ```
   确保版本 >= 8.0（支持 dense_vector）

2. **检查索引映射**
   ```bash
   curl http://localhost:39200/paper_index/_mapping
   ```
   确保有 `embedding` 和 `text` 字段

3. **查看日志**
   ```bash
   # 查看详细的检索日志
   tail -f backend/logs/service.log | grep "混合检索"
   ```

- ✅ Elasticsearch 自动处理向量检索和 BM25 的融合
