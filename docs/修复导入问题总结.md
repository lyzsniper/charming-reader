# 导入问题修复总结

## 问题列表

### 问题 1: metadata 字段冲突

**错误信息：**
```
sqlalchemy.exc.InvalidRequestError: Attribute name 'metadata' is reserved when using the Declarative API.
```

**原因：**
`metadata` 是 SQLAlchemy Declarative API 的保留字段，不能作为数据库列名。

**修复：**
将所有 `metadata` 字段重命名为 `custom_metadata`

**修改文件：**
- `backend/app/models/sql.py`
- `backend/app/services/session_service.py`
- `backend/alembic/versions/5_add_adk_session_tables.py`

---

### 问题 2: SessionService 导入错误

**错误信息：**
```
ImportError: cannot import name 'SessionService' from 'google.adk.sessions'
```

**原因：**
ADK 没有导出 `SessionService` 抽象基类供继承使用。

**修复：**
使用 Python 的鸭子类型（Duck Typing），不继承 `SessionService`，直接实现所需接口。

**修改：**
```python
# 修改前
from google.adk.sessions import SessionService
class PostgreSQLSessionService(SessionService):
    ...

# 修改后
class PostgreSQLSessionService:
    """实现 ADK SessionService 接口（鸭子类型）"""
    ...
```

**修改文件：**
- `backend/app/services/session_service.py`

---

### 问题 3: OpenAILike 模块不存在

**错误信息：**
```
ModuleNotFoundError: No module named 'llama_index.llms.openai_like'
```

**原因：**
在新版本的 llama_index (v0.14.12) 中，`OpenAILike` 类已被移除或重命名。

**修复：**
使用 `llama_index.llms.openai.OpenAI` 类，通过 `api_base` 参数配置自定义 API。

**修改：**
```python
# 修改前
from llama_index.llms.openai_like import OpenAILike

Settings.llm = OpenAILike(
    model=settings.DEFAULT_LLM_MODEL,
    api_key=settings.QWEN_API_KEY,
    api_base=settings.QWEN_BASE_URL,
    is_chat_model=True
)

# 修改后
from llama_index.llms.openai import OpenAI

Settings.llm = OpenAI(
    model=settings.DEFAULT_LLM_MODEL,
    api_key=settings.QWEN_API_KEY,
    api_base=settings.QWEN_BASE_URL,
    is_chat_model=True
)
```

**修改文件：**
- `backend/app/rag/ingestion.py`

## 技术说明

### 鸭子类型（Duck Typing）

在 Python 中，"如果它走起来像鸭子，叫起来像鸭子，那它就是鸭子"。

ADK 的 Runner 期望 `session_service` 参数实现以下方法：
- `create_session(app_name, user_id, session_id, state=None)`
- `get_session(app_name, user_id, session_id)`
- `update_session(app_name, user_id, session_id, session)`
- `delete_session(app_name, user_id, session_id)`
- `list_sessions(app_name, user_id)`

我们的 `PostgreSQLSessionService` 实现了这些方法，因此可以直接使用，无需继承。

### OpenAI 兼容 API

llama_index 的 `OpenAI` 类支持通过 `api_base` 参数配置自定义 API endpoint，适用于所有 OpenAI 兼容的 API（如 Qwen、Azure OpenAI 等）。

## 常见问题

### Q1: 启动时提示 "No module named 'xxx'"

**A:** 确保已安装所有依赖：
```bash
cd backend
pip install -r requirements.txt
```

### Q2: 数据库连接失败

**A:** 检查数据库是否运行：
```bash
docker-compose ps
```

确保 PostgreSQL 和 Elasticsearch 都在运行。

### Q3: 迁移失败

**A:** 检查迁移历史：
```bash
cd backend
alembic current
alembic history
```

如果需要，可以回滚：
```bash
alembic downgrade -1
```

### Q4: Session 未持久化

**A:** 检查数据库表是否创建成功：
```bash
psql -h localhost -p 35432 -U paperagent -d paperagent
\dt adk_*
```
