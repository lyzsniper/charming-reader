# PaperAgent Skills 使用指南

欢迎使用 PaperAgent 的技能系统！本指南将帮助您了解如何使用各项专业技能来提升学术研究效率。

## 什么是 Skills？

Skills（技能）是 PaperAgent 的专业能力模块。每个技能专注于特定的学术任务，如论文分析、文献综述、引用管理等。当您的需求匹配某个技能时，系统会自动激活该技能，为您提供专家级的帮助。

## 可用技能总览

### 1. 论文深度分析（paper-analysis）

**适用场景**：
- 需要理解一篇论文的核心内容
- 评估论文质量和贡献
- 提取论文的方法论和实验设计

**如何使用**：
```
"帮我分析这篇论文的主要贡献"
"这篇文章的方法论是什么？"
"评价一下这项研究的创新点"
```

**技能会做什么**：
- 识别论文的IMRaD结构（引言、方法、结果、讨论）
- 提取研究问题、假设和主要发现
- 评估研究的严谨性和贡献
- 识别局限性和未来研究方向

### 2. 文献综述生成（literature-review）

**适用场景**：
- 需要综合多篇相关论文
- 了解某个领域的研究现状
- 识别研究趋势和空白

**如何使用**：
```
"综述一下深度学习在NLP中的应用"
"总结这些论文的主要发现"
"分析该领域的研究演进"
```

**技能会做什么**：
- 对多篇论文进行主题聚类
- 追踪研究的时间线发展
- 比较不同方法的优劣
- 识别共识与争议
- 发现研究空白

### 3. 引用管理（citation-management）

**适用场景**：
- 需要格式化参考文献
- 检查引用格式是否正确
- 生成规范的参考文献列表

**如何使用**：
```
"帮我格式化这个引用为APA格式"
"生成IEEE格式的参考文献列表"
"检查这些引用是否完整"
```

**支持的格式**：
- APA（第7版）
- IEEE
- Chicago（第17版）
- MLA
- Harvard

### 4. RAG 优化（rag-enhancement）

**适用场景**：
- 检索结果不准确
- 回答质量不佳
- 需要改进系统性能

**如何使用**：
```
"优化检索策略"
"为什么检索结果不相关？"
"如何提高答案准确性？"
```

**技能提供的优化策略**：
- 查询改写和扩展
- 混合检索（dense + sparse）
- 结果重排序
- 上下文优化
- 幻觉检测

### 5. 数据提取（data-extraction）

**适用场景**：
- 需要提取论文中的表格数据
- 整理实验结果
- 构建性能对比矩阵

**如何使用**：
```
"提取Table 2中的数据"
"这篇论文的实验结果是什么？"
"对比这几篇论文的性能指标"
```

**技能会提取**：
- 表格数据（性能对比、数据集统计、超参数）
- 实验结果（准确率、F1分数、统计显著性）
- 图表信息（通过caption和描述）
- 模型架构参数

## 技能使用技巧

### 自动激活

PaperAgent 会根据您的问题自动激活相关技能。例如：

- 当您说"分析这篇论文"时，`paper-analysis` 技能会自动激活
- 当您说"综述"或"总结多篇论文"时，`literature-review` 技能会激活
- 当您提到"引用"或"参考文献"时，`citation-management` 技能会激活

### 手动激活

您也可以明确要求使用某个技能：

```
"使用论文分析技能帮我理解这篇文章"
"激活文献综述技能"
"用引用管理技能格式化这个引用"
```

### 查看可用技能

随时询问系统有哪些技能可用：

```
"有哪些技能可以用？"
"列出所有可用的技能"
"什么技能可以帮我做文献综述？"
```

### 技能组合

多个技能可以配合使用。例如：

1. 先用 `paper-analysis` 分析单篇论文
2. 再用 `data-extraction` 提取关键数据
3. 最后用 `citation-management` 生成引用

系统会智能管理技能的激活和停用。

     提供：
     - 论文基本信息
     - 研究问题和动机

     提供：

## 常见问题

**Q: 技能是否会自动停用？**
A: 是的。系统最多同时激活3个技能。当激活新技能且达到上限时，最早激活的技能会自动停用。您也可以手动停用不需要的技能。

**Q: 技能激活会影响响应速度吗？**
A: 技能的元数据始终加载，响应非常快。只有在技能被激活时才会加载完整内容，可能增加几百毫秒的延迟，但能大幅提升回答质量。

**Q: 可以同时使用多个技能吗？**
A: 可以。例如，在做文献综述时，`paper-analysis`、`literature-review` 和 `citation-management` 可能同时激活，协同工作。

**Q: 如何知道哪个技能被激活了？**
A: 系统会在响应中提示激活的技能。您也可以询问"当前激活了哪些技能？"

**Q: 技能的内容可以更新吗？**
A: 可以。技能是模块化的，可以独立更新。开发团队会持续改进技能内容和添加新技能。

## 最佳实践

1. **明确需求**：清楚地描述您的任务，帮助系统匹配正确的技能
2. **提供上下文**：告诉系统您正在处理的具体问题或论文
3. **分步进行**：复杂任务可以分解为多个步骤，逐步使用不同技能
4. **验证结果**：技能提供专业指导，但您应该验证关键信息
5. **反馈改进**：如果技能的帮助不符合预期，请告诉系统，帮助改进
