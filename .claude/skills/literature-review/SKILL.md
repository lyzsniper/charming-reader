# 文献综述生成技能 (Literature Review Skill)

## 目标

当用户需要对多篇相关论文进行综合分析时，使用此技能自动生成结构化的文献综述，识别研究脉络、主题演进和知识空白。

## 核心能力

本技能专注于批量处理学术文献，进行主题聚类、时间线分析、方法论对比和研究空白识别，最终生成符合学术规范的综述报告。

## 综述类型

根据用户需求，选择适当的综述类型：

### 1. 叙事性综述（Narrative Review）
- **特点**：提供研究领域的广泛概述
- **适用**：综述某个主题的整体发展
- **重点**：理论框架、主要发现、研究演进

### 2. 系统性综述（Systematic Review）
- **特点**：遵循严格的检索和筛选标准
- **适用**：全面评估特定问题的证据
- **重点**：方法透明、可复现、偏差最小化

### 3. 元分析（Meta-Analysis）
- **特点**：统计整合多项研究的定量结果
- **适用**：需要量化总结效应大小
- **重点**：统计综合、异质性分析

### 4. 范围综述（Scoping Review）
- **特点**：映射研究领域的广度
- **适用**：探索新兴领域、识别研究空白
- **重点**：概念边界、研究类型分布

## 综述工作流程

### 第一步：主题聚类

对收集的论文进行主题分组：

**聚类方法**：
1. **基于研究问题聚类**：相似研究问题的论文归为一组
2. **基于方法论聚类**：使用相似技术/方法的论文
3. **基于应用领域聚类**：针对相同应用场景的研究
4. **基于理论框架聚类**：基于相同理论基础的论文

**输出**：
```
主题 1: [主题名称]
- 论文数量: [N篇]
- 关键论文: [列出代表性论文]
- 核心观点: [该主题的主要发现]

主题 2: [主题名称]
...
```

### 第二步：时间线分析

追踪研究主题的演进：

**分析维度**：
- **早期研究（先驱工作）**：识别奠基性论文
- **中期发展（方法演进）**：追踪技术改进和理论发展
- **近期进展（前沿研究）**：最新突破和新兴方向

**时间线结构**：
```
[年份段] - [阶段特征]
代表性工作:
- [作者, 年份]: [核心贡献]
- [作者, 年份]: [核心贡献]

主要进展: [该阶段的关键突破]
技术特点: [方法论特征]
```

### 第三步：方法论对比

系统性比较不同研究的方法选择：

**对比维度**：
- **研究设计**：实验、观察、理论、综述
- **数据来源**：数据集、样本特征、数据规模
- **技术方法**：算法、模型、工具
- **评估指标**：使用的性能度量
- **结果表现**：各方法的相对优劣

**对比表格格式**：
```
| 研究 | 方法 | 数据 | 主要结果 | 优势 | 局限 |
|------|------|------|----------|------|------|
| [引用] | [方法名] | [数据集] | [关键指标] | [优点] | [不足] |
```

### 第四步：结果整合

综合不同研究的发现：

**识别共识点**：
- 哪些发现在多项研究中得到一致支持？
- 核心结论的证据强度如何？
- 是否存在收敛的理论解释？

**识别争议点**：
- 哪些问题存在矛盾的研究结果？
- 争议的可能原因（方法差异、样本差异等）
- 需要进一步研究澄清的问题

**整合表述**：
```
共识发现：
1. [发现1]：得到 [X] 项研究的支持 [引用]
2. [发现2]：...

存在争议的问题：
1. [问题1]：
   - 支持观点：[研究A, B] 发现...
   - 反对观点：[研究C, D] 发现...
   - 可能原因：...
```

### 第五步：识别研究空白

基于综述发现未来研究机会：

**空白类型**：
1. **理论空白**：缺乏理论解释或框架
2. **方法空白**：技术方法的局限或未探索的方向
3. **实证空白**：缺乏实验验证的假设
4. **应用空白**：未充分探索的应用场景
5. **人群/情境空白**：未涉及的样本或条件

**表述格式**：
```
研究空白 [编号]：[空白描述]
- 现状：[当前研究的局限]
- 机会：[为什么这是重要的研究方向]
- 建议：[具体的研究问题或方法]
```

## 综述报告结构

生成完整的文献综述报告，遵循以下结构：

```
# [主题] 文献综述

## 1. 引言
### 1.1 综述背景
[为什么这个主题重要？当前研究状况如何？]

### 1.2 综述目标
[本综述旨在回答的关键问题]

### 1.3 综述范围
[纳入标准：时间范围、文献类型、检索策略]

## 2. 理论框架
[支撑该研究领域的主要理论基础]

## 3. 主题综述
### 3.1 主题一：[主题名称]
[该主题的研究现状、主要发现、代表性研究]

### 3.2 主题二：[主题名称]
...

## 4. 研究演进
[时间线分析：从早期到近期的研究发展]

## 5. 方法论比较
[不同研究采用的方法及其优劣比较]

## 6. 综合讨论
### 6.1 主要发现总结
[跨研究的核心发现]

### 6.2 共识与争议
[一致的结论 vs 存在分歧的问题]

### 6.3 研究局限
[现有研究整体的局限性]

## 7. 研究空白与未来方向
### 7.1 识别的研究空白
[未充分研究的领域]

### 7.2 未来研究建议
[具体的研究方向和问题]

## 8. 结论
[综述的核心要点和对该领域的整体评价]

## 参考文献
[所有引用的论文，按引用格式排列]
```

## 使用指南

**何时使用此技能**
- 用户需要"文献综述"、"研究综述"
- 用户上传或提及多篇相关论文
- 用户询问"某领域的研究现状"
- 用户需要"总结研究趋势"
- 用户要求"识别研究空白"

**如何使用此技能**
1. **确认综述类型**：询问用户需要哪种类型的综述（如果不明确）
2. **收集论文**：从知识库检索或让用户指定要综述的论文
3. **批量分析**：对每篇论文进行基础分析（可配合 `paper-analysis` 技能）
4. **主题聚类**：根据相似性分组论文
5. **时间线构建**：按时间顺序追踪研究演进
6. **方法比较**：系统性比较不同方法
7. **综合发现**：整合跨研究的结果
8. **识别空白**：发现未来研究机会
9. **生成报告**：按照标准结构输出综述

**注意事项**
- 确保引用准确，每个观点都要有文献支持
- 保持客观，不偏向某些研究
- 明确区分"共识"和"争议"
- 批判性评估研究质量，不是所有论文权重相同
- 如果论文数量很多（>20篇），考虑分主题逐步综述
- 注意避免简单罗列，要进行综合分析和批判性讨论

**论文数量建议**
- 小型综述：5-10 篇论文
- 中型综述：10-30 篇论文
- 大型综述：30+ 篇论文（建议分阶段进行）

## 技能协作

- 与 `paper-analysis` 技能配合：深度分析每篇单独的论文
- 与 `citation-management` 技能配合：规范化参考文献格式
- 与 `rag-enhancement` 技能配合：优化相关文献检索

## 质量检查清单

生成综述后，检查以下要点：
- [ ] 是否明确了综述的范围和目标？
- [ ] 是否对论文进行了有意义的分组？
- [ ] 是否追踪了研究的时间演进？
- [ ] 是否比较了不同方法的优劣？
- [ ] 是否综合了跨研究的发现？
- [ ] 是否识别了共识和争议？
- [ ] 是否发现了研究空白？
- [ ] 是否所有陈述都有引用支持？
- [ ] 是否提供了批判性评价而非简单描述？
- [ ] 参考文献格式是否统一规范？
