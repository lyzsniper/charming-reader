# 文献综述大纲模板

根据不同的综述类型，选择适合的大纲结构。

## 模板 1：叙事性综述 (Narrative Review)

适用于：提供主题的广泛概述，强调理论发展和关键发现

```markdown
# [主题名称] 综述

## 1. 引言 (Introduction)
- 1.1 研究背景与重要性
- 1.2 综述范围与目标
- 1.3 文献检索策略

## 2. 理论背景 (Theoretical Background)
- 2.1 核心概念定义
- 2.2 主要理论框架
- 2.3 关键争论点

## 3. 主题回顾 (Thematic Review)
### 3.1 主题一：[主题名称]
- 理论基础
- 主要研究发现
- 代表性研究
- 当前局限

### 3.2 主题二：[主题名称]
[同上结构]

### 3.3 主题三：[主题名称]
[同上结构]

## 4. 研究演进 (Research Evolution)
- 4.1 早期研究（[年份]-[年份]）
- 4.2 中期发展（[年份]-[年份]）
- 4.3 近期趋势（[年份]-至今）

## 5. 综合讨论 (Synthesis and Discussion)
- 5.1 关键发现总结
- 5.2 理论与实践贡献
- 5.3 方法论反思
- 5.4 存在的争议

## 6. 研究空白与未来方向 (Gaps and Future Directions)
- 6.1 理论空白
- 6.2 方法论局限
- 6.3 实证研究不足
- 6.4 未来研究议程

## 7. 结论 (Conclusion)
- 主要洞见
- 对领域的整体评价
- 实践建议

## 参考文献 (References)
```

## 模板 2：系统性综述 (Systematic Review)

适用于：需要严格的方法透明度和可复现性

```markdown
# [研究问题] 系统性综述

## 摘要 (Abstract)
- 背景
- 目标
- 方法
- 结果
- 结论

## 1. 引言 (Introduction)
- 1.1 研究背景
- 1.2 综述必要性
- 1.3 研究问题（PICO格式）
  - Population (人群/对象)
  - Intervention (干预/暴露)
  - Comparison (对照)
  - Outcome (结果)

## 2. 方法 (Methods)
- 2.1 文献检索策略
  - 数据库：[列出检索的数据库]
  - 检索词：[具体的检索式]
  - 检索时间：[起止时间]
  
- 2.2 纳入与排除标准
  - 纳入标准：[列表]
  - 排除标准：[列表]
  
- 2.3 文献筛选流程
  - 初筛：[标题/摘要筛选]
  - 复筛：[全文审阅]
  - 最终纳入：[N篇]
  
- 2.4 数据提取
  - 提取的数据项：[列表]
  - 提取工具：[表格/软件]
  
- 2.5 质量评估
  - 评估工具：[如 Cochrane Risk of Bias]
  - 质量标准：[具体标准]

## 3. 结果 (Results)
- 3.1 文献检索结果
  - PRISMA流程图
  - 检索到：[N篇]
  - 最终纳入：[N篇]
  
- 3.2 纳入研究的特征
  - 研究设计分布
  - 样本量范围
  - 研究质量评分
  
- 3.3 研究发现综合
  - 按研究问题组织
  - 定性综合或定量Meta分析
  
- 3.4 质量评估结果
  - 偏倚风险分析
  - 证据强度评级

## 4. 讨论 (Discussion)
- 4.1 主要发现总结
- 4.2 证据的强度和局限性
- 4.3 与现有综述的比较
- 4.4 临床/实践意义
- 4.5 本综述的局限性

## 5. 结论 (Conclusion)
- 证据总结
- 实践建议
- 未来研究建议

## 附录 (Appendices)
- 附录A：完整检索策略
- 附录B：纳入研究列表
- 附录C：数据提取表

## 参考文献 (References)
```

## 模板 3：范围综述 (Scoping Review)

适用于：探索新兴领域、映射研究广度

```markdown
# [主题领域] 范围综述

## 1. 引言 (Introduction)
- 1.1 综述背景
- 1.2 综述目的
- 1.3 研究问题
  - 关键概念是如何定义的？
  - 主要研究类型有哪些？
  - 研究如何开展的？
  - 研究如何分布的（时间、地理、方法）？

## 2. 方法 (Methods)
- 2.1 框架选择（如 Arksey & O'Malley框架）
- 2.2 检索策略
- 2.3 纳入标准
- 2.4 数据制图方法

## 3. 结果 (Results)
- 3.1 文献概况
  - 文献数量趋势图
  - 地理分布
  - 研究类型分布
  
- 3.2 概念映射
  - 核心概念及其定义
  - 概念演进
  
- 3.3 研究特征
  - 研究设计
  - 研究方法
  - 研究对象
  
- 3.4 主要主题
  - 主题1：[描述]
  - 主题2：[描述]
  
- 3.5 研究空白
  - 概念空白
  - 方法空白
  - 人群空白

## 4. 讨论 (Discussion)
- 4.1 研究领域概览
- 4.2 研究热点与冷点
- 4.3 未来研究方向

## 5. 结论 (Conclusion)
- 领域现状
- 研究机会

## 参考文献 (References)
```

## 模板 4：批判性综述 (Critical Review)

适用于：深度评析某领域的理论和方法论

```markdown
# [主题] 批判性综述

## 1. 引言 (Introduction)
- 1.1 研究领域概述
- 1.2 批判性综述的目的
- 1.3 评析框架

## 2. 理论基础批判 (Critique of Theoretical Foundations)
- 2.1 主流理论框架
- 2.2 理论假设的合理性
- 2.3 理论的解释力与局限
- 2.4 替代性理论视角

## 3. 方法论批判 (Methodological Critique)
- 3.1 主流研究设计
- 3.2 方法论优势
- 3.3 方法论局限
  - 内部效度问题
  - 外部效度问题
  - 测量问题
- 3.4 方法创新空间

## 4. 实证证据评估 (Evaluation of Empirical Evidence)
- 4.1 证据质量
- 4.2 发现的一致性
- 4.3 因果推断的强度
- 4.4 结论的稳健性

## 5. 知识贡献与局限 (Contributions and Limitations)
- 5.1 领域进展
- 5.2 持续存在的问题
- 5.3 被忽视的视角
- 5.4 知识生产的偏见

## 6. 未来方向 (Future Directions)
- 6.1 理论发展建议
- 6.2 方法创新建议
- 6.3 研究议程重构

## 7. 结论 (Conclusion)
- 批判性洞见
- 领域重新定位

## 参考文献 (References)
```

## 模板 5：快速综述 (Rapid Review)

适用于：时间受限，需要快速概览

```markdown
# [主题] 快速综述

## 1. 背景与目的 (Background and Objectives)
- 问题紧迫性
- 综述目标

## 2. 方法简述 (Methods)
- 检索策略（简化版）
- 纳入标准
- 筛选流程

## 3. 主要发现 (Key Findings)
- 3.1 研究概况（[N]篇）
- 3.2 核心发现1
- 3.3 核心发现2
- 3.4 核心发现3

## 4. 讨论与建议 (Discussion and Recommendations)
- 证据总结
- 行动建议
- 研究局限

## 5. 结论 (Conclusion)

## 参考文献 (References)
```

## 使用建议

1. **选择合适的模板**：
   - 学术课题 → 叙事性或系统性
   - 政策决策 → 系统性或快速综述
   - 新兴领域探索 → 范围综述
   - 理论反思 → 批判性综述

2. **灵活调整**：
   - 根据论文数量调整详细程度
   - 根据研究领域特点调整章节
   - 根据目标受众调整深度

3. **保持结构清晰**：
   - 使用清晰的标题层级
   - 逻辑流畅，前后呼应
   - 每部分有明确的目的

4. **引用规范**：
   - 所有陈述都需要文献支持
   - 引用格式统一
   - 避免过度引用或引用不足
