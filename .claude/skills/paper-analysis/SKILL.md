# 论文深度分析技能 (Paper Analysis Skill)

## 目标

当用户请求分析学术论文时，使用此技能进行系统化的学术论文解读，提取结构化信息并生成专业的分析报告。

## 核心能力

本技能专注于对学术论文进行全面的结构化分析，遵循标准的学术论文评估框架。

## 分析框架

### 1. 论文结构识别（IMRaD 结构）

当分析论文时，首先识别并定位以下标准章节：

- **Title & Abstract（标题与摘要）**: 提取研究问题、方法概述、主要发现
- **Introduction（引言）**: 识别研究背景、研究问题、研究动机、研究假设
- **Methods（方法论）**: 提取实验设计、数据来源、算法/技术选择、参数设置
- **Results（结果）**: 识别关键发现、实验数据、性能指标、统计显著性
- **Discussion（讨论）**: 提取结果解释、理论贡献、实践意义、研究局限
- **Conclusion（结论）**: 总结主要贡献、未来工作方向

如果论文不遵循标准 IMRaD 结构，灵活调整但保持分析的系统性。

### 2. 关键要素提取

对于每篇论文，系统性地提取以下关键要素：

**研究问题与假设**
- 明确的研究问题（Research Question）是什么？
- 提出了哪些假设（Hypotheses）？
- 要解决的核心问题是什么？

**方法论分析**
- 采用的研究方法类型：实验研究、理论分析、案例研究、元分析等
- 实验设计：对照组设置、变量控制、样本选择
- 数据来源：数据集名称、规模、来源、代表性
- 技术/算法选择：具体使用的模型、算法、工具
- 评估指标：准确率、召回率、F1值、AUC等

**主要发现**
- 核心实验结果（用具体数值说明）
- 与基线方法的对比
- 统计显著性（p-value, confidence intervals）
- 意外发现或反直觉的结果

**创新点识别**
- 理论创新：提出新理论、新模型、新框架
- 方法创新：新算法、新技术、改进的方法
- 应用创新：新应用场景、跨领域应用
- 数据创新：新数据集、新标注方法

**局限性与批判性评估**
- 论文明确提及的局限性
- 潜在的方法论缺陷
- 样本或数据的代表性问题
- 结果的可推广性限制
- 未充分讨论的替代解释

### 3. 论文质量评估

从以下维度评估论文质量：

**研究严谨性（Rigor）**
- 研究设计是否合理？
- 方法论是否清晰可复现？
- 数据分析是否恰当？
- 结论是否有充分证据支持？

**贡献显著性（Significance）**
- 对学术领域的理论贡献
- 实践应用价值
- 对现有知识的挑战或扩展

**清晰度（Clarity）**
- 论文结构是否清晰？
- 表达是否准确？
- 图表是否有效支持论述？

### 4. 输出格式

生成结构化的分析报告，包含以下部分：

```
## 论文基本信息
- 标题：[论文标题]
- 作者：[作者列表]
- 发表年份：[年份]
- 发表期刊/会议：[出版信息]

## 研究概览
[一段话概述研究的核心内容]

## 研究问题与动机
- 研究问题：[明确的研究问题]
- 研究动机：[为什么这个问题重要]
- 研究假设：[如果有明确假设]

## 方法论分析
- 研究类型：[实验/理论/综述等]
- 数据：[数据集、样本信息]
- 技术方法：[具体算法/模型]
- 实验设计：[关键设计要素]
- 评估指标：[使用的指标]

## 主要发现与结果
- 核心发现 1：[具体描述 + 数据支持]
- 核心发现 2：[具体描述 + 数据支持]
- ...

## 创新点
- [创新点 1：理论/方法/应用等方面的创新]
- [创新点 2：...]

## 局限性与批判
- [局限性 1]
- [局限性 2]
- [批判性评估]

## 研究贡献
- 理论贡献：[对学术理论的贡献]
- 实践贡献：[对实际应用的贡献]
- 方法贡献：[对研究方法的贡献]

## 未来研究方向
- [论文提出的未来工作]
- [基于局限性的研究机会]
```

## 使用指南

**何时使用此技能**
- 用户明确要求"分析论文"、"解读这篇文章"
- 用户询问论文的方法论、结果、贡献
- 用户需要理解论文的核心创新
- 用户要求评估论文质量

**如何使用此技能**
1. 首先获取完整的论文内容（通过知识库检索或上传）
2. 按照 IMRaD 结构系统性地分析每个部分
3. 提取关键要素，不要遗漏重要信息
4. 进行批判性评估，不仅陈述事实，也提供见解
5. 生成结构化的分析报告

**注意事项**
- 保持客观，基于论文内容而非主观猜测
- 使用具体的数据和引用支持分析
- 识别论文的贡献，同时不回避局限性
- 如果论文某些部分不清晰或缺失，明确指出
- 对于技术细节，提供清晰的解释，避免过于专业的术语堆砌

## 技能协作

- 与 `citation-management` 技能配合：分析引用模式和参考文献质量
- 与 `data-extraction` 技能配合：深入提取论文中的表格和实验数据
- 与 `rag-enhancement` 技能配合：优化论文检索和相关文献发现
