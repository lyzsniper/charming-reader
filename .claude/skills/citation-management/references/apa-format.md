# APA 第7版引用格式指南

## 概述

APA（American Psychological Association）格式是心理学、教育学和社会科学领域最常用的引用格式。第7版于2019年发布，相比第6版有多处更新。

## 正文引用 (In-Text Citations)

### 基本格式

**叙述性引用**（作者是句子的一部分）：
```
Smith (2020) found that...
Smith and Jones (2020) argued...
```

**括号引用**（作者不是句子的一部分）：
```
Recent research shows... (Smith, 2020).
The findings are significant (Smith & Jones, 2020).
```

### 多位作者

**2位作者**：
- 叙述性：Smith and Jones (2020)
- 括号：(Smith & Jones, 2020)
- 注意：叙述性用"and"，括号用"&"

**3位及以上作者**：
- 首次引用：(Smith et al., 2020)
- 后续引用：(Smith et al., 2020)
- 第7版新规则：直接使用 et al.，不再要求首次列出所有作者

### 多篇文献同时引用

**同一括号内多个引用**：
```
(Brown, 2019; Smith, 2020; Wilson, 2021)
```
- 按作者姓氏字母顺序排列
- 用分号分隔

**同一作者多篇文献**：
```
(Smith, 2019, 2020, 2021)
```

**同一作者同年多篇**：
```
(Smith, 2020a, 2020b)
```

### 直接引用

**短引用**（少于40词）：
```
Smith (2020) stated that "direct quotes require page numbers" (p. 15).
或
Research shows "direct quotes require page numbers" (Smith, 2020, p. 15).
```

**长引用**（40词及以上）：
```
Smith (2020) described the phenomenon:
    This is a block quote. It should be indented without quotation marks.
    Block quotes are used for passages of 40 words or more. (p. 15)
```

### 特殊情况

**无作者**：
```
使用标题前几个词：("Title of Article," 2020)
```

**机构作者**：
```
首次：(National Institute of Health [NIH], 2020)
后续：(NIH, 2020)
```

**个人通讯**：
```
(J. Smith, personal communication, January 15, 2020)
注意：个人通讯不出现在参考文献列表中
```

## 参考文献列表 (References)

### 基本规则

1. **排序**：按作者姓氏字母顺序
2. **缩进**：悬挂缩进（首行顶格，后续行缩进）
3. **双倍行距**
4. **作者姓名**：姓氏在前，缩写在后

### 期刊论文

**基本格式**：
```
Author, A. A., Author, B. B., & Author, C. C. (Year). Title of article. 
Title of Journal, volume(issue), pages. https://doi.org/xxxxx
```

**示例**：
```
Smith, J. M., & Johnson, L. K. (2020). Deep learning approaches in natural 
language processing. Journal of Artificial Intelligence Research, 67, 123-145. 
https://doi.org/10.1613/jair.1.12345
```

**注意事项**：
- 期刊名称：斜体，每个主要词首字母大写
- 卷号：斜体
- 期号：不斜体，放在括号中
- DOI：优先使用，格式为完整 URL

**无 DOI 的期刊论文**：
```
Brown, R. (2019). Traditional methods in research. Journal of Methods, 
15(3), 200-215.
```

**在线优先发表**（无卷期号）：
```
Wilson, T. (2021). Emerging trends in AI. Journal of Technology. 
Advance online publication. https://doi.org/10.xxxx
```

### 书籍

**整本书**：
```
Author, A. A. (Year). Title of book (Edition ed.). Publisher. 
https://doi.org/xxxxx
```

**示例**：
```
Mitchell, T. M. (1997). Machine learning. McGraw-Hill.

Goodfellow, I., Bengio, Y., & Courville, A. (2016). Deep learning. 
MIT Press. https://www.deeplearningbook.org
```

**编辑的书籍**：
```
Editor, E. E. (Ed.). (Year). Title of book. Publisher.

或多位编辑：
Editor, E. E., & Editor, F. F. (Eds.). (Year). Title of book. Publisher.
```

**书籍章节**：
```
Chapter Author, C. A. (Year). Title of chapter. In E. E. Editor (Ed.), 
Title of book (pp. xxx-xxx). Publisher.
```

**示例**：
```
Hinton, G. E. (2012). A practical guide to training restricted Boltzmann 
machines. In G. Montavon, G. B. Orr, & K.-R. Müller (Eds.), Neural networks: 
Tricks of the trade (2nd ed., pp. 599-619). Springer.
```

### 会议论文

**已出版的会议论文集**：
```
Author, A. A. (Year). Title of paper. In E. E. Editor (Ed.), Title of 
proceedings (pp. xxx-xxx). Publisher.
```

**示例**：
```
Devlin, J., Chang, M.-W., Lee, K., & Toutanova, K. (2019). BERT: 
Pre-training of deep bidirectional transformers for language understanding. 
In Proceedings of the 2019 Conference of the North American Chapter of the 
Association for Computational Linguistics (pp. 4171-4186). 
Association for Computational Linguistics.
```

**会议摘要/Poster**：
```
Author, A. A. (Year, Month). Title [Conference presentation]. Conference Name, 
City, State, Country.
```

### 学位论文

**硕士/博士论文**：
```
Author, A. A. (Year). Title of dissertation [Doctoral dissertation, 
Name of Institution]. Database or Archive. URL
```

**示例**：
```
Chen, L. (2020). Applications of deep learning in medical image analysis 
[Doctoral dissertation, Stanford University]. Stanford Digital Repository. 
https://purl.stanford.edu/xxxxx
```

### 网络资源

**网页**：
```
Author, A. A. (Year, Month Day). Title of page. Site Name. URL
```

**示例**：
```
OpenAI. (2023, March 14). GPT-4 technical report. OpenAI. 
https://openai.com/research/gpt-4
```

**无日期的网页**：
```
Author, A. A. (n.d.). Title of page. Site Name. URL
```

### 数据集

```
Author, A. A. (Year). Title of data set (Version number) [Data set]. 
Publisher. https://doi.org/xxxxx
```

**示例**：
```
Deng, J., Dong, W., Socher, R., Li, L.-J., Li, K., & Fei-Fei, L. (2009). 
ImageNet: A large-scale hierarchical image database (Version 1.0) [Data set]. 
http://www.image-net.org/
```

### 软件/代码

```
Author, A. A. (Year). Title of software (Version number) [Computer software]. 
Publisher or URL
```

**示例**：
```
Paszke, A., Gross, S., Massa, F., Lerer, A., Bradbury, J., Chanan, G., ... 
Chintala, S. (2019). PyTorch: An imperative style, high-performance deep 
learning library (Version 1.3) [Computer software]. https://pytorch.org/
```

## 第7版主要变化

1. **et al. 使用**：3位及以上作者直接使用 et al.
2. **DOI 格式**：使用完整 URL（https://doi.org/xxxxx）
3. **作者数量**：最多列出20位作者
4. **位置信息**：出版社不再需要城市/州
5. **检索日期**：在线资源通常不需要检索日期
6. **电子书页码**：可使用章节、段落或标题定位

## 标点符号和格式

### 标题大小写

**期刊论文和书名**（Sentence case）：
- 只有首字母和专有名词大写
- 示例：Deep learning for natural language processing

**期刊名称**（Title Case）：
- 主要词首字母都大写
- 示例：Journal of Artificial Intelligence Research

### 斜体使用

- 书名、期刊名称：斜体
- 卷号：斜体
- 论文标题：不斜体
- 期号、页码：不斜体

### 缩写

- 常见缩写：ed., Vol., No., p., pp.
- 第7版：简化了一些缩写规则
- 月份可缩写（Jan., Feb.）

## 常见错误

1. ❌ 混淆 "&" 和 "and"
   - 正确：叙述用 "and"，括号用 "&"

2. ❌ 期刊名称使用 sentence case
   - 正确：期刊名称用 Title Case

3. ❌ 不必要的缩写（Vol., No.）
   - 第7版不再需要这些缩写

4. ❌ 包含数据库名称
   - 除非特殊情况，不需要 "Retrieved from Database"

5. ❌ DOI 格式错误
   - 正确：https://doi.org/10.xxxx
   - 错误：doi:10.xxxx 或 DOI: 10.xxxx
