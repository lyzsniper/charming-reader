# Chicago 引用格式指南（第17版）

## 概述

Chicago Manual of Style (CMOS) 第17版是人文学科、历史学和艺术领域常用的引用格式。Chicago 格式提供两种引用系统：

1. **Notes-Bibliography System（注释-参考文献系统）**：使用脚注或尾注
2. **Author-Date System（作者-日期系统）**：类似 APA，用括号引用

本指南主要介绍这两种系统。

---

## 系统一：Notes-Bibliography System

### 适用领域
文学、历史、艺术等人文学科

### 正文引用

使用**上标数字**按顺序标注：

```
The study provides significant insights.¹ Further research² confirms these findings.
```

### 脚注/尾注格式

**首次引用**（完整信息）：
```
1. John Michael Smith, Deep Learning for Natural Language Processing 
(Cambridge, MA: MIT Press, 2020), 45.
```

**后续引用**（简短格式）：
```
2. Smith, Deep Learning, 67.
```

**连续引用同一来源**：
```
3. Ibid., 89.
```
注：Ibid. = ibidem（拉丁语"同上"）

### 参考文献列表 (Bibliography)

**基本规则**：
- 按作者姓氏字母顺序排列
- 使用悬挂缩进
- 作者名：姓氏在前

#### 书籍

**单作者**：
```
脚注：
1. Tom M. Mitchell, Machine Learning (New York: McGraw-Hill, 1997), 23.

参考文献：
Mitchell, Tom M. Machine Learning. New York: McGraw-Hill, 1997.
```

**多位作者**：
```
脚注：
1. Ian Goodfellow, Yoshua Bengio, and Aaron Courville, Deep Learning 
(Cambridge, MA: MIT Press, 2016), 105.

参考文献：
Goodfellow, Ian, Yoshua Bengio, and Aaron Courville. Deep Learning. 
Cambridge, MA: MIT Press, 2016.
```

**编辑的书**：
```
脚注：
1. Gary Montavon, Grégoire B. Orr, and Klaus-Robert Müller, eds., 
Neural Networks: Tricks of the Trade, 2nd ed. (Berlin: Springer, 2012), 50.

参考文献：
Montavon, Gary, Grégoire B. Orr, and Klaus-Robert Müller, eds. Neural 
Networks: Tricks of the Trade. 2nd ed. Berlin: Springer, 2012.
```

**书籍章节**：
```
脚注：
1. Geoffrey E. Hinton, "A Practical Guide to Training Restricted Boltzmann 
Machines," in Neural Networks: Tricks of the Trade, 2nd ed., ed. Gary Montavon, 
Grégoire B. Orr, and Klaus-Robert Müller (Berlin: Springer, 2012), 601.

参考文献：
Hinton, Geoffrey E. "A Practical Guide to Training Restricted Boltzmann 
Machines." In Neural Networks: Tricks of the Trade, 2nd ed., edited by 
Gary Montavon, Grégoire B. Orr, and Klaus-Robert Müller, 599-619. 
Berlin: Springer, 2012.
```

#### 期刊论文

```
脚注：
1. Yann LeCun, Yoshua Bengio, and Geoffrey Hinton, "Deep Learning," 
Nature 521, no. 7553 (2015): 438, https://doi.org/10.1038/nature14539.

参考文献：
LeCun, Yann, Yoshua Bengio, and Geoffrey Hinton. "Deep Learning." 
Nature 521, no. 7553 (2015): 436-444. https://doi.org/10.1038/nature14539.
```

**要点**：
- 论文标题：双引号，Title Case
- 期刊名称：斜体，不缩写
- 卷期号：vol, no. (脚注可省略vol.)
- 脚注：引用特定页码
- 参考文献：列出完整页码范围

#### 会议论文

```
脚注：
1. Jacob Devlin et al., "BERT: Pre-training of Deep Bidirectional Transformers 
for Language Understanding," in Proceedings of the 2019 Conference of the North 
American Chapter of the Association for Computational Linguistics (Minneapolis, 
MN: Association for Computational Linguistics, 2019), 4173.

参考文献：
Devlin, Jacob, Ming-Wei Chang, Kenton Lee, and Kristina Toutanova. "BERT: 
Pre-training of Deep Bidirectional Transformers for Language Understanding." 
In Proceedings of the 2019 Conference of the North American Chapter of the 
Association for Computational Linguistics, 4171-4186. Minneapolis, MN: 
Association for Computational Linguistics, 2019.
```

#### 学位论文

```
脚注：
1. Li Chen, "Applications of Deep Learning in Medical Image Analysis" 
(PhD diss., Stanford University, 2020), 45.

参考文献：
Chen, Li. "Applications of Deep Learning in Medical Image Analysis." 
PhD diss., Stanford University, 2020.
```

#### 网络资源

**网页**：
```
脚注：
1. OpenAI, "GPT-4 Technical Report," OpenAI, March 14, 2023, 
https://openai.com/research/gpt-4.

参考文献：
OpenAI. "GPT-4 Technical Report." OpenAI. March 14, 2023. 
https://openai.com/research/gpt-4.
```

**在线期刊论文**：
```
与印刷版相同，添加 DOI 或 URL
```

## 系统二：Author-Date System

### 适用领域
科学、社会科学（物理学、生物学、心理学等）

### 正文引用

**基本格式**（类似 APA）：
```
Recent research (Smith 2020, 45) shows that...
Smith (2020, 67) argues...
```

**多位作者**：
```
2位作者：(Smith and Jones 2020)
3位及以上：(Smith et al. 2020)
```

**多个引用**：
```
(Brown 2019; Smith 2020; Wilson 2021)
```

### 参考文献列表 (References)

#### 书籍

**单作者**：
```
Mitchell, Tom M. 1997. Machine Learning. New York: McGraw-Hill.
```

**多位作者**：
```
Goodfellow, Ian, Yoshua Bengio, and Aaron Courville. 2016. Deep Learning. 
Cambridge, MA: MIT Press.
```

**书籍章节**：
```
Hinton, Geoffrey E. 2012. "A Practical Guide to Training Restricted Boltzmann 
Machines." In Neural Networks: Tricks of the Trade, 2nd ed., edited by 
Gary Montavon, Grégoire B. Orr, and Klaus-Robert Müller, 599-619. 
Berlin: Springer.
```

#### 期刊论文

```
LeCun, Yann, Yoshua Bengio, and Geoffrey Hinton. 2015. "Deep Learning." 
Nature 521 (7553): 436-44. https://doi.org/10.1038/nature14539.
```

**要点**：
- 年份紧跟作者姓名
- 期刊名称不缩写
- 卷号不使用 vol.
- 页码范围可简化（436-44 而非 436-444）

#### 会议论文

```
Devlin, Jacob, Ming-Wei Chang, Kenton Lee, and Kristina Toutanova. 2019. 
"BERT: Pre-training of Deep Bidirectional Transformers for Language 
Understanding." In Proceedings of the 2019 Conference of the North American 
Chapter of the Association for Computational Linguistics, 4171-86. 
Minneapolis, MN: Association for Computational Linguistics.
```

#### 学位论文

```
Chen, Li. 2020. "Applications of Deep Learning in Medical Image Analysis." 
PhD diss., Stanford University.
```

#### 网络资源

```
OpenAI. 2023. "GPT-4 Technical Report." OpenAI. March 14, 2023. 
https://openai.com/research/gpt-4.
```

## 两种系统的选择

| 特征 | Notes-Bibliography | Author-Date |
|------|-------------------|-------------|
| 适用学科 | 人文学科 | 科学、社会科学 |
| 正文引用 | 上标数字¹ | (Smith 2020) |
| 完整信息 | 脚注/尾注 + Bibliography | 仅 References |
| 阅读流畅性 | 不打断正文 | 括号可能分散注意力 |
| 引用细节 | 可添加详细评论 | 简洁明了 |
| 页码引用 | 容易 | 需在括号内标注 |

**选择建议**：
- 历史、文学研究 → Notes-Bibliography
- 科学实验报告 → Author-Date
- 跨学科项目 → 根据主要领域选择

## 特殊情况处理

### 多次引用同一作者同年作品

```
Author-Date系统：
Smith 2020a
Smith 2020b

Notes-Bibliography系统：
通常不需要字母标识，通过完整标题区分
```

### 次要来源引用

**引用转引**：
```
正文：(Freud 1930, quoted in Smith 2020, 45)

References中只列出Smith 2020，不列Freud 1930
```

### 经典作品

```
脚注可同时给出原文和译文信息：
1. Aristotle, Nicomachean Ethics, trans. W. D. Ross (Oxford: Oxford 
University Press, 1925), bk. 2, chap. 6.
```

### 未出版材料

```
脚注：
1. Mary Johnson, "Title of Unpublished Manuscript," unpublished manuscript, 
last modified February 15, 2023, Microsoft Word file.

参考文献：
Johnson, Mary. "Title of Unpublished Manuscript." Unpublished manuscript. 
Last modified February 15, 2023. Microsoft Word file.
```

## 缩写规则

### 拉丁缩写

- **Ibid.** (ibidem)：同上，连续引用同一来源
- **Et al.** (et alii)：和其他人
- **Cf.** (confer)：比较
- **E.g.** (exempli gratia)：例如
- **I.e.** (id est)：即
- **N.b.** (nota bene)：注意
- **Ca.** (circa)：大约（用于日期）

### 月份（Author-Date系统可缩写）

```
January → Jan.    July → July（不缩写）
February → Feb.   August → Aug.
等等
```

## 常见错误

1. ❌ 混淆两种系统
   - 不要在同一文档中混用脚注和作者-日期引用

2. ❌ 脚注和参考文献格式混淆
   - 脚注：作者名正序，单一来源
   - 参考文献：作者姓氏在前，完整信息

3. ❌ 缩写使用不当
   - Ibid. 只能用于连续引用
   - Et al. 只用于3位以上作者

4. ❌ 标题大小写错误
   - Chicago 使用 Title Case（主要词首字母大写）
   - 不同于 APA 的 sentence case

5. ❌ 出版地信息缺失
   - Chicago 要求提供出版城市
   - 主要城市可省略州名（如 New York, Chicago）

## 格式检查清单

**Notes-Bibliography系统**：
- [ ] 使用上标数字顺序编号
- [ ] 脚注使用完整信息
- [ ] 后续引用使用简短格式
- [ ] Bibliography按字母顺序排列
- [ ] 作者姓名：脚注正序，Bibliography倒序

**Author-Date系统**：
- [ ] 括号引用包含作者和年份
- [ ] References按作者姓氏字母顺序排列
- [ ] 年份紧跟作者姓名
- [ ] 使用 "and" 连接作者（不用&）
- [ ] 3位以上作者使用 et al.
