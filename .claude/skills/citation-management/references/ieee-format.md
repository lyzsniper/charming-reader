# IEEE 引用格式指南

## 概述

IEEE（Institute of Electrical and Electronics Engineers）引用格式广泛用于工程、计算机科学和技术领域。其特点是使用数字编号系统，按照引用在文中出现的顺序编号。

## 正文引用 (In-Text Citations)

### 基本格式

**数字编号**：
```
The study [1] showed that...
According to Smith [2], the method...
Multiple studies [3]-[5] have demonstrated...
```

### 编号规则

1. **首次引用**：按文中出现顺序分配编号[1], [2], [3]...
2. **重复引用**：使用相同编号
3. **多个引用**：
   - 连续：[1]-[3] 或 [1], [2], [3]
   - 不连续：[1], [4], [7]

### 位置

**句中引用**：
```
The algorithm described in [1] outperforms...
Smith [2] and Jones [3] independently developed...
```

**句末引用**：
```
Deep learning has revolutionized NLP [1].
Recent advances have been significant [2], [3].
```

### 特殊情况

**引用特定页面**：
```
As stated in [1, p. 25], the results...
```

**引用特定章节**：
```
See [1, Sec. II] for details.
```

**引用图表**：
```
As shown in Fig. 1 of [2]...
```

## 参考文献列表 (References)

### 基本规则

1. **编号**：按照文中引用顺序，[1], [2], [3]...
2. **缩进**：使用悬挂缩进
3. **作者名称**：首字母缩写在前，姓氏在后
4. **标点**：使用引号括住论文标题

### 期刊论文

**基本格式**：
```
[#] A. A. Author, B. B. Author, and C. C. Author, "Title of paper," 
Abbrev. Title of Journal, vol. x, no. x, pp. xxx-xxx, Month Year. 
doi: xxxxx
```

**示例**：
```
[1] J. M. Smith and L. K. Johnson, "Deep learning approaches in natural 
language processing," J. Artif. Intell. Res., vol. 67, pp. 123-145, 
Mar. 2020. doi: 10.1613/jair.1.12345
```

**要点**：
- 作者名：首字母缩写 + 姓氏
- 3位及以上作者：最后用 "and"
- 论文标题：双引号，sentence case
- 期刊名：缩写，斜体
- 卷号：vol. x（不斜体）
- 期号：no. x
- 页码：pp. xxx-xxx
- 日期：月份缩写 + 年份
- DOI：如有，添加 doi: xxxxx

### 期刊名称缩写

IEEE 要求期刊名称缩写。常见缩写：

```
IEEE Transactions on Pattern Analysis and Machine Intelligence
→ IEEE Trans. Pattern Anal. Mach. Intell.

Journal of Machine Learning Research
→ J. Mach. Learn. Res.

Nature Communications
→ Nat. Commun.

Proceedings of the IEEE
→ Proc. IEEE
```

**缩写规则**：
- 单词保留首字母和重要辅音
- 去除冠词（the, a, an）
- 去除介词（of, in, on）

### 会议论文

**基本格式**：
```
[#] A. A. Author, "Title of paper," in Proc. Abbrev. Conf. Name, 
City, State/Country, Year, pp. xxx-xxx. doi: xxxxx
```

**示例**：
```
[2] J. Devlin, M.-W. Chang, K. Lee, and K. Toutanova, "BERT: Pre-training 
of deep bidirectional transformers for language understanding," in Proc. 
2019 Conf. North Amer. Chapter Assoc. Comput. Linguistics, Minneapolis, 
MN, USA, 2019, pp. 4171-4186. doi: 10.18653/v1/N19-1423
```

**已出版的会议论文集**：
```
[3] G. E. Hinton, "A practical guide to training restricted Boltzmann 
machines," in Neural Networks: Tricks of the Trade, 2nd ed., G. Montavon, 
G. B. Orr, and K.-R. Müller, Eds. Berlin, Germany: Springer, 2012, 
pp. 599-619.
```

### 书籍

**整本书**：
```
[#] A. A. Author, Title of Book, xth ed. City, State/Country: Publisher, 
Year.
```

**示例**：
```
[4] T. M. Mitchell, Machine Learning. New York, NY, USA: McGraw-Hill, 1997.

[5] I. Goodfellow, Y. Bengio, and A. Courville, Deep Learning. 
Cambridge, MA, USA: MIT Press, 2016.
```

**书籍章节**：
```
[#] A. A. Author, "Title of chapter," in Title of Book, xth ed., 
E. E. Editor, Ed. City, State/Country: Publisher, Year, pp. xxx-xxx.
```

### 学位论文

**博士论文**：
```
[#] A. A. Author, "Title of dissertation," Ph.D. dissertation, Dept. Abbrev., 
Univ. Name, City, State/Country, Year.
```

**示例**：
```
[6] L. Chen, "Applications of deep learning in medical image analysis," 
Ph.D. dissertation, Dept. Comput. Sci., Stanford Univ., Stanford, CA, 
USA, 2020.
```

**硕士论文**：
```
[#] A. A. Author, "Title of thesis," M.S. thesis, Dept. Abbrev., 
Univ. Name, City, State/Country, Year.
```

### 技术报告

```
[#] A. A. Author, "Title of report," Company/Institution, City, 
State/Country, Tech. Rep. Number, Month Year.
```

**示例**：
```
[7] OpenAI, "GPT-4 technical report," OpenAI, San Francisco, CA, USA, 
Tech. Rep., Mar. 2023. [Online]. Available: https://openai.com/research/gpt-4
```

### 专利

```
[#] A. A. Inventor, "Title of patent," Country Patent Number, Month Day, Year.
```

**示例**：
```
[8] J. Smith and M. Jones, "Method for deep neural network training," 
U.S. Patent 10 123 456, Oct. 15, 2019.
```

### 标准

```
[#] Title of Standard, Standard Number, Year.
```

**示例**：
```
[9] IEEE Standard for Floating-Point Arithmetic, IEEE Std 754-2019, 2019.
```

### 网络资源

**网页/在线文档**：
```
[#] A. A. Author. (Year, Month Day). Title. Publisher/Site Name. 
[Online]. Available: URL
```

**示例**：
```
[10] A. Vaswani et al. (2017). Attention is all you need. arXiv. 
[Online]. Available: https://arxiv.org/abs/1706.03762
```

**无作者的网页**：
```
[11] "Deep learning," Wikipedia. Accessed: Mar. 15, 2023. [Online]. 
Available: https://en.wikipedia.org/wiki/Deep_learning
```

### 数据集

```
[#] A. A. Author. (Year). Title of dataset (Version) [Data set]. 
Publisher. [Online]. Available: URL
```

**示例**：
```
[12] J. Deng, W. Dong, R. Socher, L.-J. Li, K. Li, and L. Fei-Fei. (2009). 
ImageNet: A large-scale hierarchical image database. [Data set]. 
[Online]. Available: http://www.image-net.org/
```

### 软件

```
[#] A. A. Author. (Year). Title of software (Version) [Software]. 
[Online]. Available: URL
```

**示例**：
```
[13] A. Paszke et al. (2019). PyTorch: An imperative style, high-performance 
deep learning library (Ver. 1.3). [Software]. [Online]. 
Available: https://pytorch.org/
```

## 缩写规则

### 月份缩写
```
January   → Jan.      July      → Jul.
February  → Feb.      August    → Aug.
March     → Mar.      September → Sep.
April     → Apr.      October   → Oct.
May       → May       November  → Nov.
June      → Jun.      December  → Dec.
```

### 常用缩写
```
volume           → vol.
number           → no.
pages            → pp.
page             → p.
edition          → ed.
editor(s)        → Ed(s).
chapter          → ch.
section          → Sec.
figure           → Fig.
table            → Table
equation         → Eq.
and              → and (不缩写)
et alii          → et al.
```

### 学位缩写
```
Bachelor of Science       → B.S.
Master of Science         → M.S.
Doctor of Philosophy      → Ph.D.
Master of Business Admin. → M.B.A.
```

### 地理位置
```
USA, UK, China (国家不缩写)
NY, CA, TX (美国州名缩写)
```

## 作者名称处理

### 作者数量

**1-2位作者**：
```
[1] A. Smith, "Title," ...
[2] A. Smith and B. Jones, "Title," ...
```

**3位及以上作者**：
```
[3] A. Smith, B. Jones, and C. Brown, "Title," ...
```

**超过6位作者**（可选）：
```
[4] A. Smith et al., "Title," ...
```

### 名称格式

**西方名字**：
```
John Michael Smith → J. M. Smith
Mary Elizabeth Jones → M. E. Jones
```

**复合姓氏**：
```
Jean-Claude Van Damme → J.-C. Van Damme
María García-Martínez → M. García-Martínez
```

**中文名字**：
```
Zhang Wei → W. Zhang
Li Xiaoming → X. Li 或 X.-M. Li
```

## 常见错误

1. ❌ 作者姓名顺序错误
   - 错误：Smith, J. M.
   - 正确：J. M. Smith

2. ❌ 期刊名称不缩写
   - 错误：Journal of Artificial Intelligence Research
   - 正确：J. Artif. Intell. Res.

3. ❌ 论文标题不使用引号
   - 错误：Deep learning for NLP
   - 正确："Deep learning for NLP"

4. ❌ 卷号使用斜体
   - 错误：vol. 67（斜体）
   - 正确：vol. 67（不斜体）

5. ❌ 编号格式错误
   - 错误：1. 或 (1)
   - 正确：[1]

6. ❌ DOI 格式错误
   - 错误：https://doi.org/10.xxxx
   - 正确：doi: 10.xxxx（IEEE 格式不使用 URL 形式）

## 格式检查清单

- [ ] 引用按文中出现顺序编号
- [ ] 使用方括号 [1], [2] 格式
- [ ] 作者名：首字母缩写 + 姓氏
- [ ] 论文标题使用双引号
- [ ] 期刊名称正确缩写并斜体
- [ ] 卷号使用 vol. x（不斜体）
- [ ] 页码使用 pp. xxx-xxx
- [ ] 月份正确缩写
- [ ] DOI 使用 doi: xxxxx 格式
- [ ] 所有缩写正确使用（vol., no., pp., ed.）
