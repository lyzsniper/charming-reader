# 引用管理技能 (Citation Management Skill)

## 目标

当用户需要处理学术引用时，使用此技能规范化引用格式、验证引用完整性、生成参考文献列表，确保符合学术出版标准。

## 核心能力

本技能支持多种主流学术引用格式，能够自动检测和纠正引用错误，验证引用一致性，并生成规范的参考文献列表。

## 支持的引用格式

### 1. APA 格式 (American Psychological Association)
**常用领域**：心理学、教育学、社会科学

**特点**：
- 作者-年份引用系统
- 正文引用：(Smith, 2020) 或 Smith (2020)
- 多位作者：(Smith & Jones, 2020) 或 (Smith et al., 2020)

**详细规范**：参考 `references/apa-format.md`

### 2. IEEE 格式 (Institute of Electrical and Electronics Engineers)
**常用领域**：工程、计算机科学、技术

**特点**：
- 数字引用系统
- 正文引用：[1] 或 [1]-[3]
- 按引用顺序编号

**详细规范**：参考 `references/ieee-format.md`

### 3. Chicago 格式
**常用领域**：历史、艺术、人文学科

**特点**：
- 支持两种子格式：注释-参考文献系统 / 作者-日期系统
- 灵活性高，适合人文研究

**详细规范**：参考 `references/chicago-format.md`

### 4. MLA 格式 (Modern Language Association)
**常用领域**：文学、语言学、人文学科

**特点**：
- 作者-页码引用系统
- 正文引用：(Smith 25) 或 Smith argues... (25)
- 强调作者和页码

### 5. Harvard 格式
**常用领域**：广泛使用，尤其在英国

**特点**：
- 作者-日期系统
- 与 APA 类似但有细微差异
- 正文引用：(Smith 2020)

## 核心功能

### 功能 1：识别引用格式

当用户提供引用或论文时，自动识别使用的引用格式。

**识别线索**：
- 正文引用模式：(作者, 年份) → APA/Harvard
- 正文引用模式：[数字] → IEEE
- 正文引用模式：(作者 页码) → MLA
- 脚注/尾注系统 → Chicago

**输出**：
```
检测到的引用格式：[格式名称]
置信度：[高/中/低]
依据：[识别理由]
```

### 功能 2：格式化引用

将非规范的引用转换为标准格式。

**输入示例**：
```
Smith, John, "Deep Learning", 2020, Journal of AI
```

**输出（APA格式）**：
```
Smith, J. (2020). Deep learning. Journal of AI.
```

**输出（IEEE格式）**：
```
[1] J. Smith, "Deep learning," Journal of AI, 2020.
```

### 功能 3：验证引用完整性

检查引用信息是否完整。

**必需元素检查**：

期刊论文：
- [ ] 作者姓名
- [ ] 发表年份
- [ ] 论文标题
- [ ] 期刊名称
- [ ] 卷号（如有）
- [ ] 期号（如有）
- [ ] 页码（如有）
- [ ] DOI（推荐）

书籍：
- [ ] 作者/编者
- [ ] 出版年份
- [ ] 书名
- [ ] 出版社
- [ ] 出版地（某些格式需要）

会议论文：
- [ ] 作者
- [ ] 年份
- [ ] 论文标题
- [ ] 会议名称
- [ ] 会议地点
- [ ] 页码

**问题识别**：
- 缺失作者 → "警告：未提供作者信息"
- 缺失年份 → "错误：必须提供发表年份"
- 缺失标题 → "错误：必须提供论文标题"

### 功能 4：交叉引用验证

验证正文引用与参考文献列表的一致性。

**检查项目**：

1. **孤立引用检查**：
   - 正文中引用但参考文献列表中没有 → 错误
   - 参考文献列表中有但正文中未引用 → 警告

2. **信息一致性检查**：
   - 正文引用的年份与参考文献列表的年份是否匹配
   - 作者姓名拼写是否一致
   - 多作者论文的 "et al." 使用是否正确

**输出报告**：
```
交叉引用验证报告：
✓ 共检查 [N] 条正文引用
✗ 发现 [M] 个问题：

1. [Smith, 2020] 正文引用但参考文献列表缺失
2. [Jones et al., 2019] 参考文献列表中有但正文未引用
3. [Brown, 2021] 年份不一致：正文为2021，参考文献为2020
```

### 功能 5：生成参考文献列表

根据指定格式生成完整的参考文献列表。

**排序规则**：
- **APA/Harvard/MLA**：按作者姓氏字母顺序
- **IEEE**：按引用顺序编号
- **Chicago**：取决于子格式

**处理特殊情况**：
- 同一作者多篇论文：按年份排序
- 同一作者同年多篇论文：使用 2020a, 2020b
- 无作者论文：按标题排序
- 机构作者：按机构名称排序

### 功能 6：引用格式转换

在不同引用格式之间转换。

**使用场景**：
- 投稿期刊要求不同格式
- 从学位论文转换为期刊论文

**转换示例**：
```
原格式（APA）：
Smith, J., & Jones, M. (2020). Deep learning for NLP. 
Journal of AI, 15(3), 123-145.

转换后（IEEE）：
[1] J. Smith and M. Jones, "Deep learning for NLP," 
Journal of AI, vol. 15, no. 3, pp. 123-145, 2020.
```

## 使用指南

### 何时使用此技能

- 用户需要"格式化引用"
- 用户询问"如何引用"
- 用户提供参考文献需要规范化
- 用户需要生成参考文献列表
- 用户需要检查引用格式是否正确
- 用户需要转换引用格式

### 如何使用此技能

**场景 1：格式化单个引用**
1. 识别用户提供的引用信息
2. 询问需要的引用格式（如果未指定）
3. 检查信息完整性
4. 生成规范化的引用
5. 提供格式说明

**场景 2：生成参考文献列表**
1. 收集所有需要引用的文献信息
2. 确认引用格式要求
3. 规范化每条引用
4. 按格式要求排序
5. 生成完整列表

**场景 3：验证引用一致性**
1. 提取正文中的所有引用
2. 提取参考文献列表
3. 进行交叉验证
4. 生成问题报告
5. 提供修复建议

**场景 4：格式转换**
1. 识别当前格式
2. 确认目标格式
3. 解析引用元素
4. 按新格式重组
5. 输出转换结果

### 注意事项

1. **作者姓名处理**：
   - 注意姓氏和名字的顺序（不同文化差异）
   - 中文作者姓名的英文表示
   - 复合姓氏的处理

2. **特殊字符**：
   - 标题中的大小写规则（title case vs sentence case）
   - 特殊符号和数学公式
   - 非英语字符（变音符号等）

3. **DOI 和 URL**：
   - 优先使用 DOI
   - URL 的访问日期（某些格式需要）
   - 在线资源的引用

4. **多来源信息**：
   - 引用次要来源时注明
   - 个人通讯的引用
   - 未发表材料的引用

## 常见引用错误

### 1. 作者数量错误
**错误**：(Smith, Jones, & Brown, 2020)
**正确（APA 第7版）**：(Smith et al., 2020)
**说明**：3位及以上作者首次引用即使用 et al.

### 2. 标点符号错误
**错误**：Smith J. (2020). Deep Learning. Journal of AI.
**正确（APA）**：Smith, J. (2020). Deep learning. Journal of AI.
**说明**：姓名后需逗号，标题句首字母大写

### 3. 页码格式错误
**错误**：pp. 123-145（IEEE格式）
**正确（IEEE）**：pp. 123-145
**注意**：不同格式对 pp. 的使用有不同规定

### 4. 日期格式不一致
**错误**：混用不同日期格式（2020, 2020年, 20年）
**正确**：统一使用（2020）

### 5. 期刊名称不规范
**错误**：J. of AI
**正确（完整）**：Journal of Artificial Intelligence
**正确（缩写）**：J. Artif. Intell.（根据期刊要求）

## 输出示例

### 示例 1：规范化参考文献

**用户输入**：
```
帮我规范化这个引用：
John Smith, Mary Jones, "A deep learning approach for natural 
language processing", published in Conference on AI, 2020, pages 100-110
```

**技能输出（APA格式）**：
```
规范化引用（APA 第7版格式）：

Smith, J., & Jones, M. (2020). A deep learning approach for natural 
language processing. In Proceedings of the Conference on AI (pp. 100-110).

引用要点：
- 作者：使用姓氏和首字母缩写
- 标题：仅首字母和专有名词大写
- 会议：使用 "In Proceedings of..."
- 页码：使用 pp.

如需其他格式，请告诉我（IEEE, MLA, Chicago等）。
```

### 示例 2：生成参考文献列表

**用户输入**：
```
生成这些论文的参考文献列表（IEEE格式）：
1. Smith 2020, "Deep Learning"
2. Jones 2019, "Neural Networks"
3. Brown 2021, "AI Applications"
```

**技能输出**：
```
参考文献（IEEE格式）：

[1] J. Smith, "Deep learning," [需要补充期刊/会议信息], 2020.
[2] M. Jones, "Neural networks," [需要补充期刊/会议信息], 2019.
[3] R. Brown, "AI applications," [需要补充期刊/会议信息], 2021.

注意：为生成完整的IEEE格式引用，请提供以下信息：
- 期刊名称或会议名称
- 卷号、期号、页码（期刊论文）
- 会议地点（会议论文）
- DOI（如有）
```
